# data/raw

Указатели на внешние дампы и лицензии. Сами дампы сюда не кладём.

- Файлы > 10 МБ и полный ГАР/ФИАС / GeoNames `RU.zip` не вендорятся.
- CC BY-SA и ODbL остаются только в этом дереве (как указатели), не в `data/curated/`.
- Смотри `SOURCE.md` в подкаталоге источника.
- Опциональный fetch: `python scripts/fetch_dump.py --source ID` пишет **вне** git (`--dest` внутри репозитория — ошибка).
