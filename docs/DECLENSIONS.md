# Склонение топонимов

Витрина — [README](../README.md). Оглавление — [docs/README.md](README.md).

Нормативная база: Розенталь; Грамота.ру; словари географических названий.
Морфоанализаторы (pymorphy2/3, Natasha, pyphrasy) — предложение, не истина.
Золотой слой: `data/declensions/`. Гидронимы — `hydronyms-major.csv` (не `cities-major.csv`); оронимы, МО, годонимы и микротопонимы — отдельные таблицы.

## Поля таблицы

`id,type_code,lemma,yo,gender,paradigm,declinable,nom,gen,dat,acc,ins,pre,loc2,review,source`

| поле | смысл |
|---|---|
| nom…pre | шесть падежей |
| loc2 | второй предложный / местный (*на Дону*) |
| gender | m / f / n / pl |
| paradigm | noun_m2, noun_f1, noun_f3, noun_n_ovo, adj_m, mixed_phrase, pl_tantum, indecl, agency-head |
| declinable | always / never / optional / not_with_generic |
| review | gold / auto / needs_review |

Уникальность в файле — **`(id, lemma)`** (DEC-DECL-002), не уникальный `id`. У ФОИВ две строки на один id: аббревиатура и полное имя (`foiv:mvd` → «МВД» и «Министерство внутренних дел»). Не переписывать золото в `foiv:mvd#head`.

## Правила

1. Славянские освоенные имена склоняются: *в городе Москве*, *на берегу Волги*.
2. Средний род на -e/-o как приложение часто не склоняется: *из города Видное*.
3. -ово/-ино традиционно склоняются (*в Переделкине*); современный разговорный вариант допустим — `optional`.
4. Многословные и прилагательные: *в Нижнем Новгороде*, *из Жуковского*.
5. Города на -ов/-ин: творительный **-om**, не -ым: *под Пушкином*.
6. Несклоняемые: Сочи, Тольятти, Улан-Удэ, большинство аббревиатур ФОИВ.
7. Гидронимы: *на Волге*, *на Дону* (`loc2`), *на Байкале*, *на Ладожском озере*.
8. Ведомства: склоняется стержневое существительное (*в Министерстве внутренних дел*); аббревиатура обычно несклоняема (*в МВД России*). Росгвардия склоняется.

## Конвейер ежедневного обновления

1. Строка с `review=gold` не трогать без issue и ссылки на норму.
2. Новое высокочастотное имя — ручная строка или `review=needs_review`.
3. Массовая автогенерация pymorphy — только в `data/declensions/queue.csv` (не ресурс datapackage; DEC-DECL-001). CLI: `python scripts/declensions_queue.py --id … --lemma …` пишет очередь, не `regions`/`cities-major`/`agencies`. В канон автоформы попадают лишь с `review=needs_review`. `review=gold` морфоанализатор не ставит.
4. Фикстуры нельзя ломать: Москва; Нижний Новгород; Сочи; Орёл; Пушкин (*Пушкином*); Жуковский; Домодедово; Волга (*Волги*); Дон (*на Дону*); МВД / Министерство внутренних дел.
5. Приёмка `needs_review` → `gold` только поштучно, со ссылкой на норму в `source`. Не автопереводом. Остаток может остаться `needs_review`.
